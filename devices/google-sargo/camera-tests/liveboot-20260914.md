# Sargo liveboot camera trial — 14 September 2026

Camera image quality is still unaccepted. This trial uses the designated test
phone and a disposable USB-root liveboot; the storage host remains connected.

## Completed

- Booted a coherent `7.1.2-0.pocketfed.sdm670.11.fc46.aarch64` kernel/DTB/module
  bundle. It already contains the LC898219XI lens power-sequence correction.
  Systemd handoff passed with enforcing SELinux, matching modules and an overlay
  root. This establishes boot infrastructure, not camera capture.
- Configured private Wi-Fi and key-authenticated SSH access in the fixture.
  Access credentials, host keys and raw device logs are excluded from this PR.
- Cloned pinned upstream sources and built as an unprivileged user on the phone
  with two jobs, including the RPM checks. Installed `libdng 0.2.2-1`,
  `libmegapixels 0.2.3-3` and `megapixels 2.1.0-5`, all `.fc46.native`, using
  `dnf`. Installed libcamera/IPA/tools `0.7.2-4.fc46` for comparison.
- Corrected the bootstrap to use Fedora's `feedbackd-devel` provider and include
  the private D-Bus launcher and image-test tools. Direct systemd execution of
  the source script in `/var/tmp` was denied by SELinux; native builds ran
  through the normal SSH development login with enforcing policy unchanged.
- Verified the actual evdev Volume Up and Volume Down capabilities. The gate's
  37 host regressions and visible launcher's 11 subprocess tests pass.

## Camera enumeration issue

CCI initially failed probing with `deferred probe timeout, ignoring dependency`
and error `-110`. CAMSS existed, but neither sensor nor the lens was registered.
After all CCI suppliers were bound and available, one explicit bind of the
unbound CCI controller succeeded. IMX363, IMX355 and LC898219XI then appeared.
The strict power check reported all three suspended with no camera handles.

This was a recovery in the running trial. The initial boot did **not** pass
camera enumeration. A subsequent boot must establish whether a camera-specific
probe ordering or timeout adjustment prevents the failure.
